Package com.example.shotlog

Pantalles de l'aplicació (Activities): splash, inici de sessió i registre, inici amb els menús, nou entrenament, registre de trets, llista d'entrenaments, detall, edició, guia, preferències i compte. També hi ha les funcions d'extensió comunes (Utilidades.kt) i les dades de prova (DatosEjemplo).
