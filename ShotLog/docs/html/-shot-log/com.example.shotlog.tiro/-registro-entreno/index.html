RegistroEntreno

class RegistroEntreno(val modalidad: Modalidad, val modo: ModoEntreno, val disparosMaximos: Int = 0)

Lleva la cuenta de un entreno mientras se dispara: disparos, series de 10 y totales. No sabe nada de la pantalla: la Activity solo le pasa coordenadas y lee el resultado.

Parameters

disparosMaximos

en competición, 60 o 40; en entrenamiento, 0 (sin límite).
